# SemVer Hello World

Простой учебный проект для демонстрации семантического
версионирования (Semantic Versioning).

## Запуск

```bash
node index.js
```

## Правила версионирования

Проект использует формат MAJOR.MINOR.PATCH:

- MAJOR — несовместимые изменения.
- MINOR — новые функции с обратной совместимостью.
- PATCH — исправления ошибок.

## История релизов

- v1.0.0 — начальная версия приложения.
- v1.1.0 — добавлен вывод текущей даты и времени.
- v1.2.0 — добавлен вывод имени пользователя.
- v1.2.1 — исправлена обработка пустого имени.

Подробности изменений находятся в разделе Releases репозитория.
